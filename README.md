# Haunted Rent

Game design prototype built through coworking and brainstorming with AI agents.

## Overview

This repository contains early-stage game design documentation, UI mockups, and prototype screens for an untitled haunted property management game concept.

## Contents

| File | Description |
|------|-------------|
| `gameDesign/haunted-tenancy-gdd.html` | Original game design document |
| `gameDesign/haunted-tenancy-gdd-v1.2.html` | Updated GDD v1.2 |
| `gameDesign/main-screen-mockup.html` | Primary screen UI prototype |
| `gameDesign/ui-mockup.html` | Full interface mockup |

## How It Was Made

Every idea, layout, and design decision in this repo emerged from iterative back-and-forth between a human game designer and LLM-based coding agents. The agents generated HTML mockups, proposed mechanics, refined visuals, and refactored structure on the fly.
