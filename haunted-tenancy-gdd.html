Haunted Tenancy

Game Design Document — v1.1
Genre: 2D Horror Comedy Management Sim
Platform: Godot Engine / Pixel Art

Elevator Pitch: Papers, Please meets survival horror management. You're a cheapskate tenant in a cursed house. Rent is impossibly low — because every room is haunted. Inspect rooms daily against safety checklists. Get cursed when you mess up. Save $2,000 to escape. Don't die.

1. MDA Framework

Mechanics (Rules)

  • Core verb: Room inspection via safety checklists — toggle ✓ SAFE / ⚠ FLAG
  • Resources: Money ($), Time (day timer), Health (injury/curse slots)
  • Progression: Weekly room unlocks (W1: 3, W2: 5, W3: 8, W4: 11, W5+: 12 max)
  • Constraints: Time limit, curse debuffs stack, equipment costs money, 3+ curses = game over

Dynamics (Behavior)

  • Risk/reward: Spend on equipment to prevent curses, or save faster but risk spirals
  • Time triage: More rooms = less time per room → harder skip decisions
  • Cascade effect: Curse → weaker inspection → more mistakes → more curses
  • Routine mastery: Learn entity rules, get fast, then new entities break routine

Aesthetics (Experience)

  • Tension: Timer + escalating threats + consequence accumulation
  • Dark humor: Bureaucratic horror framing, absurd premise
  • Relief: End-of-day survival, successful clears, savings milestone
  • Competence: Learning patterns, optimizing routine, mastering economy

Time constraint: Day ends at 6pm game time ≈ 5 real minutes. Each room inspection consumes time. Skip room = instant but $10 penalty + entity grows stronger.

3. Room System (Two Tracks)

Two approaches per room:
SAFE TRACK: Inspect + fill checklist → $10 per room. Safe, steady income, room stays active next day.
EXILE TRACK: 4-phase process → ritual combat → banish entity permanently. High risk, $50–100 reward, room cleared forever. Failing combat = game over.

3.1 Room Map → Room Scene

  1. House map: clickable grid of rooms (e.g. 3×4). Each room shows entity icon + status (pending/cleared/skipped/banished)
  2. Click room → room scene loads in center panel
  3. Room composed of: base tileset (study/bedroom/kitchen/bathroom/hallway) + entity prop layer + anomaly visual layer
  4. Click objects in room → inspection pop-up opens (Papers, Please style)

3.2 Object Inspection (Papers, Please Style)

Click any object in room view → small overlay window opens with detailed pixel view of that specific object/area. Shows either normal or anomalous state based on daily anomaly generation. Some objects have sub-hotspots within pop-up (e.g., click candle area → pop-up shows candle count + arrangement).

Anomaly Generation (Per Room, Per Day)

Each day, system randomly marks 2–4 checklist items as anomalous for each room. Visual layer conditionally renders anomalies on room scene + pop-ups. Difficulty gradient: W1 = 2 obvious anomalies, W4 = 4 subtle anomalies.

Example: Demon's Study — Day 14 ───────────────────────────────────── ✓ Summoning circle absent (floor clean) ⚠ Candles ≤3 (4 candles visible, arc pattern) ✓ Cross intact on wall ⚠ No sulfur smell (yellow haze near vent) ✓ Temp <98°F (reads 72°F) ⚠ No inverted symbols (faint pentagram on wall) ───────────────────────────────────── System picks: items 2, 4, 6 anomalous → visual clues rendered

3.4 EXILE TRACK — Phase 1: Clue Gathering

Enter room. Click objects freely. Each inspection yields a clue card — no toggling, no answering. Just observation. Clue cards stored in journal for PC research.

CLUE CARDS COLLECTED — Demon's Study ───────────────────────────────────── 🔍 CANDLES: "4 candles arranged in circular pattern" 🔍 FLOOR: "Faint white chalk marks, 5-point outline" 🔍 WALL: "Small inverted pentagram near bookshelf" 🔍 THERMOMETER: "73°F — within normal range" 🔍 CROSS: "Mounted on wall, no damage" 🔍 AIR VENT: "Faint yellow mist seeping from grate" ───────────────────────────────────── 4 of 6 objects inspected — 4 clue cards collected

Key design: Player must decide when to stop investigating and move to research. More clues = better identification accuracy, but costs daytime minutes. Too few clues → risk misidentifying the entity → wrong exile attempt = disaster.

Clue matching logic: Each entity profile lists 5–7 symptoms. System compares collected clue cards against each profile. Overlapping symptoms between entities create ambiguity (witch also has candles + symbols but no chalk marks). Player must discern pattern.

Profile unlocking: Wiki starts with Ghost, Poltergeist, Vampire entries. Other entities unlock as player encounters them. Player can browse freely, study patterns between turns.

3.7 EXILE TRACK — Phase 4: Ritual Combat

Return to room with exile items prepared → initiate ritual. Combat is turn-based, rock-paper-scissors: enemy telegraphs move → player picks correct counter-item from inventory. Time paused during combat. No HP sponges, no minions — knowledge/memory puzzle under pressure.

Turn Resolution

  1. Enemy tell — player sees text hint + animation. Visibility depends on prep tier.
  2. Player picks item — from inventory. Correct item → ritual advances. Wrong item → damage + item wasted.
  3. Player action resolves — e.g. "You splash Holy Water. Flames douse. Demon shrieks — ritual advances."
  4. Enemy action resolves — damage dealt if wrong counter was used. If correct, enemy blocked.
  5. Next turn — sequence repeats. All 4 correct counters → Final EXORCISM → victory.

Wrong Counter = Damage + Setback

Demon's tell: "Flame gathering" (expect Holy Water) Player picks: Crucifix ❌ "You raise the crucifix. Demon laughs. Fireball strikes — 5 damage. Crucifix wasted." → Ritual stalls. Demon gains advantage (+2 damage next turn). → Next turn: same move repeats. MUST counter correctly. → 2–3 wrong counters = death.

INCOME: + $50 daily savings (vs $120 normal rent — you "save" $70 conceptually) + $10 per correctly cleared room (SAFE track) + $50–$100 per banished entity (EXILE track, one-time) + $30 weekly bonus (all rooms inspected that week) EXPENSES: − Exile items: $5–$15 per item (one exile kit = $15–$35 total per entity) − Equipment (SAFE track): $5–$30 per item − Cures: $7–$30 per treatment − Skip penalty: −$10 per skipped room − Flee combat: −$20 penalty ───────────────────────────────────────── ESCAPE GOAL: $2,000 saved

Tension: Equipment buys safety, but delays escape. Aggressive saving risks curse spiral. Player must find optimal pace.

8. Narrative & Tone

Genre: Dark comedy, bureaucratic horror.
Core joke: You are not heroic. You're a miser who refuses to pay $1,200 rent. For $200/month you'll live with actual demons.

Tone inspirations:

  • Papers, Please — bureaucratic dread
  • What We Do In The Shadows — supernatural mundanity
  • House of Leaves — unsettling domestic horror

Sample Flavor Text

  • Landlord email: "Room 4 has a 'presence.' We're calling it an amenity. No rent adjustment."
  • Entity description: "Standard Issue Revenant, Class B. Non-violent unless provoked. Provoked = looked at directly."
  • End-of-day: "You hear faint crying from Room 3. You put in earplugs. $200/month. Two hundred."

9. Edge Cases & Balance

RiskMitigation
Curse death spiral Free weekly rest day, mercy mechanic (3rd mistake in a row → warning, not extra curse), emergency loan option
Dominant strategy No universal equipment; entity variety forces different prep per room type. Equipment has charges, not infinite
Overwhelming late game Skip-room mechanic, equipment auto-clears tough rooms, optional rest days. Banished rooms permanently reduce daily workload.
Boring early game Tutorial day has "emergency" (ghost breaks confinement), creates immediate stake. First exile attempt tutored.
Visual boredom Room states change based on: entity mood, active curses, equipment used, day count, season
Clarity of failure End-of-day review shows exactly which checklist items were wrong and why. Combat shows which counter was wrong.
Runaway economy $2,000 goal with escalating expenses + exile kit costs keeps target at ~25–40 day range
Combat trivialization Preparation quality gates tell visibility. Must earn clues + buy items. Memory check + curse penalties keep tension.
Wiki = walkthrough Clues are partial — never 100% match. Red herrings. Entity profiles intentionally ambiguous at edges. Player must interpret.
Combat feels disconnected Clue gathering and wiki research happen in real daytime (no pause). Combat is gated by knowledge earned during play.

12. Unique Selling Points

  1. Familiar verb, fresh context: Papers, Please inspection loop applied to horror comedy survival
  2. Two-track risk system: SAFE track (steady income, stay alive) vs EXILE track (permanently banish entity, big reward, risk death)
  3. Knowledge-based combat: World of Horror style ritual exile. No grinding — you win by correctly identifying entity and memorizing its banishing sequence. Wrong = die.
  4. Compounding consequences: Curses aren't binary HP loss — they alter how you perceive and interact with the game, including combat tells
  5. Dark comedic tone: Bureaucratic horror is under-explored in games. Landlord emails about "energy-neutral rooms."
  6. Tight economic tension: Every dollar on safety delays escape; every skipped room risks death. Exile kits cost $15–$35 — high stakes.
  7. Weekly escalation fits flow channel: New rooms break routine, mastery of old threats creates satisfaction loop. Banished rooms stay gone — tangible progress.
